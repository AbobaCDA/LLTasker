# Forge Tasks

Таск-трекер для Windows: задачи с дедлайнами, напоминания в Windows и Telegram, синхронизация между устройствами.

## Скачать

[Релизы](../../releases) → `Forge-Tasks-Setup-<версия>.exe` → запустить установщик.

Приложение работает сразу, без аккаунта: задачи хранятся локально. Синхронизация и Telegram включаются в настройках. Установщик не подписан, поэтому Windows может показать предупреждение SmartScreen — «Подробнее» → «Выполнить в любом случае».

## Возможности

- Задачи: приоритет, проект, теги, заметки, повторения (день, будни, неделя, месяц).
- Напоминания: уведомления Windows при запущенном приложении и сообщения Telegram, когда ПК выключен. У каждой задачи свой набор интервалов. Плюс утренний дайджест в боте.
- Быстрый ввод одной строкой — и в приложении, и в боте.
- Синхронизация через Supabase, работа в трее, автозапуск с Windows, автообновление.

## Быстрый ввод

```
оплатить хостинг завтра 18:30 !2 #работа за день
позвонить врачу в пятницу в 10
отчёт 06.11.2026 09:00 по будням за 2 часа
```

Разбираются «сегодня / завтра / в пятницу / через 3 дня», даты `06.10`, `06.10.2026`, `6 октября`,
время `18:30`, `в 18`, `в 7 вечера`, приоритет `!0…!3`, `#проект`, `+тег`, «за час», «без напоминаний»,
повторения «каждый день / по будням / каждую неделю / ежемесячно».

## Где лежат данные

- Локально: `%APPDATA%\ForgeTasks\forge-tasks.json` (сессия — в `cloud-auth.bin`, шифруется средствами Windows).
- В облаке: Supabase, доступ только к своим строкам (RLS). Папку с данными можно открыть из приложения.

## Разработка

```bash
npm ci
npm start          # запуск приложения
npm test           # тесты: схема БД, разбор ввода, синхронизация, напоминания
npm run dist:win   # сборка установщика
```

```
desktop/                     Electron: окно, трей, синхронизация, локальное хранилище
task-manager.html            Интерфейс (открывается и без Electron — в демо-режиме)
supabase/                    Схема БД, Edge Functions (бот, привязка Telegram, доставка напоминаний)
tests/                       Тесты на Node, без сети
```

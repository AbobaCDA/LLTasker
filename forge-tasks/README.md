# Forge Tasks

Таск-трекер для Windows с облачной синхронизацией и напоминаниями в Telegram. Родственный проект [La2 Trader Timer](https://github.com/AbobaCDA/La2TraderTimer-LTT-): тот же каркас (Electron + Supabase + Edge Functions + pg_cron), но вместо торговых смен — задачи.

## Что умеет

- **Задачи с дедлайном.** Приоритет (4 уровня), проект, теги, заметки, точное время или «весь день».
- **Повторения.** Каждый день, по будням, еженедельно, ежемесячно. Следующее вхождение создаётся автоматически при закрытии текущего — с тем же временем и напоминаниями.
- **Напоминания в двух местах.** Уведомления Windows, когда приложение запущено, и сообщения Telegram, когда ПК выключен. У каждой задачи свой набор: «за 1 день», «за 1 час», «за 10 минут» и т. д. Плюс мягкая подсказка через 5 минут после дедлайна.
- **Утренний дайджест** в Telegram: просроченное и задачи на сегодня, один раз в сутки в удобное время.
- **Быстрый ввод человеческим языком** — и в приложении, и в боте.
- **Облачная синхронизация.** Вход в аккаунт синхронизирует задачи между устройствами; без аккаунта всё работает локально. Правки без интернета встают в очередь и уходят в облако сами.
- **Работа в трее** с автозапуском Windows, автообновлением и горячей клавишей Ctrl+N для быстрого добавления.

## Быстрый ввод

Одна строка — вся задача:

```
оплатить хостинг завтра 18:30 !2 #работа за день
позвонить врачу в пятницу в 10
отчёт 06.11.2026 09:00 по будням за 2 часа
тренировка ежедневно в 7 утра +здоровье
купить фильтр для воды без напоминаний
```

Разбираются: `сегодня / завтра / послезавтра`, `в пятницу`, `через 3 дня`, `через 2 недели`, `06.10`, `06.10.2026`, `2026-11-01`, `6 октября`, время `18:30`, `в 18`, `18ч`, `в 7 вечера`; `!0…!3` или «важно»; `#проект`; `+тег`; `за 30 минут`, `за 2 часа`, `за день`, `без напоминаний`; `каждый день`, `по будням`, `каждую неделю`, `ежемесячно`.

## Telegram

| Команда | Что делает |
| --- | --- |
| `/start` | Код привязки аккаунта (10 минут) |
| `/today` · `/week` · `/all` | Список задач на сегодня, неделю, всё |
| `/add текст` | Добавить задачу |
| `/done ID` · `/snooze ID 15м` · `/due ID завтра 10:00` · `/delete ID` | Закрыть, перенести, задать срок, удалить |
| `/digest 09:00` · `/digest off` | Утренний дайджест |
| `/settings` · `/cancel` · `/help` | Настройки, отмена ввода, справка |
| `/stats` | Сводка для владельца |

Под каждой задачей есть кнопки: готово, +15 минут, +1 час, завтра 10:00, изменить срок, повтор, напоминания, удаление.

## Установка

Пошаговая инструкция (репозиторий → Supabase → бот → приложение): [`docs/SETUP-GUIDE.md`](docs/SETUP-GUIDE.md).

Коротко:

1. Скачайте `Forge-Tasks-Setup-<версия>.exe` со страницы [релизов](../../releases) и запустите установщик.
2. Добавьте первую задачу строкой сверху — приложение работает сразу, в локальном режиме.
3. Для синхронизации: **Настройки → Облако и аккаунт**, укажите Supabase URL и publishable key, создайте аккаунт и подтвердите e-mail.
4. Для Telegram: отправьте боту `/start`, введите полученный код в том же разделе настроек.

Приложение не подписано сертификатом Authenticode, поэтому Windows может показать предупреждение SmartScreen. Проверка подписи обновлений отключена.

## Где лежат данные

- Локально: `%APPDATA%\ForgeTasks\forge-tasks.json`, сессия — `cloud-auth.bin` (шифруется средствами Windows).
- В облаке: таблицы `tasks` и `profiles` проекта Supabase, доступ строго по вашему `user_id` (RLS).

Папку с данными можно открыть из приложения: **Настройки → открыть папку**.

## Разработка

```bash
npm ci          # зависимости приложения
npm start       # запуск Electron
npm test        # тесты: схема БД, разбор ввода, слияние данных, планировщик
npm run dist:win
```

Структура:

```
desktop/                     Electron: главный процесс, трей, синхронизация, хранилище
task-manager.html            Интерфейс (открывается и без Electron — в демо-режиме)
supabase/migrations/         Схема БД: задачи, очередь напоминаний, RLS
supabase/functions/          Edge Functions: бот, привязка, доставка напоминаний
supabase/functions/_shared/  Общие модули: разбор ввода и работа с часовыми поясами
tests/                       Тесты (Node, без сети)
docs/DEPLOYMENT.md           Развёртывание облака, бота и расписания
```

Тесты гоняют реальный PostgreSQL (PGlite, WASM): проверяются триггеры перестройки напоминаний, создание повторяющихся вхождений, защита от повторной отправки и изоляция данных по RLS.
